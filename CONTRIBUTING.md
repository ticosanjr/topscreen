# Contributing to TopScreen

Thanks for your interest! This project is a live-effects plugin for OBS.

## Principles

1. **Live only.** No post-production features (timeline, cutting, manual
   keyframe, export). If an effect only makes sense after recording, it does not
   belong here.
2. **Light by default.** GPU, no encode, no readback, no per-frame allocation.
3. **Testable core.** Logic goes into `src/core/` (no OBS) and gets a test. The
   OBS layer (`src/`, outside `core/`) should be thin.
4. **Portable.** Windows + Linux, X11 + Wayland.

## Structure

- `src/core/` — pure, tested core. Do not include `<obs-module.h>` here.
- `src/` — OBS layer (filter, compositor, settings, input, dock).
- `data/` — shader, locales, presets, sounds, fonts, cursors, udev.
- `tests/` — core tests.

### Generated assets

- **Cursors:** `data/cursors/atlas.rgba` + `atlas.json` are generated by
  `python3 tools/make-cursor-atlas.py` (reads XCursor themes from
  `/usr/share/icons` and draws the classics). Run it again if the styles change.
- **Font:** `data/fonts/DejaVuSans-Bold.ttf` (for the key overlay).
- **Sounds:** `data/sounds/*.wav` (click sound).
- **Wallpapers:** `data/wallpapers/*.jpg` — bundled Unsplash photos; see
  `data/wallpapers/SOURCES.txt`.

## Workflow

1. Create a branch.
2. Implement the change.
3. **Run the tests:** `./tests/run.sh` (must pass).
4. **Run the header check:** `./tools/check-obs-headers.sh` (compiles the
   plugin against the real OBS headers, without installing it).
5. If you changed logic, add/update tests in `tests/`.
6. If you changed an effect/scope, update `docs/EFFECTS.md`, `docs/TASKS.md`.
7. Open the PR describing what changed and how to verify it.

## Code style

- Formatting: `.clang-format` (run `clang-format -i`).
- C++20, 4 spaces, `namespace topscreen` (+ `::core` for the core).
- Names: `snake_case` for functions/variables, `PascalCase` for types.
- Comments in Portuguese (the project text is PT-BR; code/identifiers in English).

## Adding a setting

1. Add the key in `src/core/keys.hpp`.
2. Add the field in `src/core/config.hpp`.
3. Map it in `src/ts-settings.cpp` (`config_defaults`, `config_load`, `config_store`).
4. Expose it in the UI in `src/ts-properties.cpp` + texts in `data/locale/*.ini`.
5. Support it in the preset in `src/core/preset.cpp` and in `data/presets/*.json`.

## Adding a test

```cpp
#include "core/meu_modulo.hpp"
#include "test_framework.hpp"

TEST(meu_modulo_caso) {
    CHECK(alguma_coisa());
    CHECK_NEAR(value, 1.0, 1e-9);
}
```

## Building the plugin

See `docs/BUILD.md`. You need libobs (+ obs-frontend-api/Qt6 for the dock).
