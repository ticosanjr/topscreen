# Distribution assets

- `icon.svg` — editable source of the plugin icon.
- `icon.png` — 512×512 raster version for stores, READMEs and release pages.
- `screenshots/obs-overview.png` — real OBS 30 window with a scene using the
  TopScreen FX filter (background, padding, shadow and custom cursor).
- `screenshots/topscreen-scene.png` — the demo scene used for the screenshots.
- `screenshots/reading-mode.png` — illustrative Reading-mode view (dim outside the
  selection). It is a mock-up of the effect, not a captured OBS window.

The demo scene is a static HTML mock-up used only for marketing images. The OBS
overview was captured from a real OBS 30.0.2 session under Xvfb.
